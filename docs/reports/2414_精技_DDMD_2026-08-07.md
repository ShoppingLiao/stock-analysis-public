## 【A】公司總覽

### 1. 這是一間什麼公司？

精技電腦（Unitech Computer Co., Ltd.）1979 年成立，總部台北內湖。前身為「精技工業」，1991 年更名，是**台灣中型 IT 通路商**，事業分為兩大 segment：
- **Channel Business Operation（資訊通路）**：代理 / 經銷 / 配送 / 維護各類電腦、周邊、伺服器、網通、顯示器、印表機、企業解決方案
- **Automatic Identification Data Collection（自動識別，AIDC）**：條碼、掃描器、行動計算裝置、RFID solution 開發、製造、行銷

2026 H1 因 **AI server / GPU / 企業 IT 升級週期**受惠，**上半年營收 203.33 億 YoY +46.2%**、6 月單月 50.92 億 **YoY +87.3%** 創新高，從穩健低毛利通路商**轉身為 AI capex 受惠題材股**。

### 2. 主要產品是什麼？分別賣給誰？

| 業務 | 內容 | 終端客戶 |
|---|---|---|
| **Channel（通路，主體 ~90%）**| 代理 Apple、HP、Dell、Lenovo、聯想、NVIDIA GPU / AI server、Cisco、Aruba 等品牌 | 企業、政府、SI、經銷商、零售 |
| **AI Server 通路**（2025-2026 新爆發引擎）| NVIDIA GPU server、Enterprise AI infra、GPU workstation | 企業 AI 建置、SI、金融 / 電信客戶 |
| **AIDC（自動識別）**| 條碼掃描器、行動裝置、POS 系統、RFID solution | 零售、物流、製造、醫療 |
| **顯示 / 數位看板** | Digital signage、Kiosk、Video Wall | 交通、零售、公共空間 |
| **企業 solution**| Networking、儲存、Server、雲端解決方案 | 中大型企業 IT 部門 |
| **售後 / 維護** | 專業服務、SLA、產品維護 | 全客群 |

**核心收入結構**：通路業務約 85-90%（其中 AI server / GPU 已是主要成長 driver），AIDC 自有品牌 10-15%。

### 3. 主要客戶是誰？

- **上游供應商**：Apple、HP、Dell、Lenovo、NVIDIA、Cisco、Aruba、Zebra 等品牌
- **下游企業客戶**：金融業、電信業、政府機構、教育、中大型企業 IT
- **經銷商 / SI 通路夥伴**：轉售給零售與中小企業
- **AIDC 產業客戶**：零售連鎖、物流業（黑貓、宅配通）、製造工廠、醫院

**客戶集中度**：通路業務極分散（10,000+ 中小企業客戶），AI server 客戶隨企業 AI 建置浪潮擴大。

### 4. 性感題材

- 🎯 **企業 AI server 通路爆發** — 2026 H1 營收 YoY +46%、6 月 YoY +87%，AI server 建置浪潮受惠
- 🎯 **NVIDIA GPU 通路代理** — Enterprise AI 建置需通路商整合，精技位置對
- 🎯 **殖利率 5.39%** — 中型高息股定位，穩健配息基礎
- 🎯 **AIDC 條碼 / RFID 業務** — 自有品牌 + 隨零售 / 物流 AI 化升級
- 🎯 **ROE 18%** — 低毛利但高周轉商業模式運作良好
- 🎯 **2026 Q1 EPS 1.28** — 若延續，全年 EPS 有機會挑戰 5-6 元
- 🎯 **系統整合 solution 佔比提升** — 從純通路商轉為 SI 提高單筆毛利

**注意**：精技不是「頂級成長股」，屬於「AI 建置浪潮 spillover 受惠的中型通路商」，thesis 品質與研華、嘉澤、藥華藥等不同層級，DDMD 評分應對應調整。

## 【B】大大毛多四維度評估

### B.1 大（產業）

#### 成長主因
- **企業 AI server 建置浪潮**：2026-2027 中大型企業從 POC 走向量產 AI 建置，需通路商整合、配送、維護
- **傳統 IT 升級週期**：Windows 11 upgrade、AI PC 換機潮
- **AIDC 產業升級**：零售 POS、物流條碼、醫療 RFID 全面升級

#### 需求來源
- **企業 AI infra**：金融、電信、政府、製造導入 AI server / GPU
- **AI PC**：Copilot+ PC、AI NPU 導入帶動 B2B 換機潮
- **智慧零售 / 物流 / 醫療**：AIDC 產品 upgrade cycle
- **政府 / 公部門專案**：IT 現代化預算

#### 滲透率
- 台灣企業 AI server 滲透率 <20%，長期 3-5x 空間
- AI PC 滲透率 <10%，2026-2027 爆發期
- AIDC 傳統業務相對成熟

#### 逆風情境
- 台灣 IT 通路市場集中度高：聯強（2347）、精誠（6214）、大聯大（3702）主導
- 大型通路商規模經濟強、精技中型定位夾在中間
- 通路業務毛利極低（<10%），任何價格戰都會擠壓 net margin
- AI server 熱潮若在 2027 消化期回檔，通路業務首當其衝

#### B.1 評分：**3/5**
IT 通路業本質是穩健低毛利產業，7.9% CAGR。AI server 通路 spillover 是短期 2-3 年紅利，但無法讓「通路商本質」變成頂級成長產業。給 3 分是合理，比一般通路 2 分高（因 AI 受惠），比 IPC / 半導體設備 4-5 分低（因產業本質）。

### B.2 大（市佔）

#### 市佔地位
- **台灣 IT 通路排名**：中型玩家，遠不及聯強（2347，龍頭 30%+）、精誠（6214）、大聯大（3702）規模
- **AI server 通路**：新賽道剛啟動，精技靠既有企業客戶關係卡位
- **AIDC 業務**：台灣中型玩家，非龍頭（龍頭是 Zebra、Honeywell、Datalogic 等國際品牌代理）
- **市值 90 億**：屬台股中小型股

#### 護城河類型
- **既有企業客戶關係**：長期經營的金融、電信、政府客戶
- **多品牌代理權**：Apple / HP / Dell / NVIDIA 等重點品牌授權
- **SI 服務能力**：從純通路轉 SI + solution 是差異化路徑
- **AIDC 自有品牌**：有部分自主研發能力

**但整體護城河偏弱**：通路業務進入門檻中低，中國 / 東南亞通路商切入台灣市場的風險存在。

#### 定價權
- 通路業務議價力極低（7.4% 毛利說明一切）
- SI / solution 業務議價力中等
- AIDC 自有品牌議價力較強
- 整體毛利率結構性偏低是這個商業模式的天花板

#### B.2 評分：**2/5**
中型通路商，非龍頭、非利基專家、無強護城河。市佔位置在台灣 IT 通路業排在聯強、精誠、大聯大之後。給 2 分是公允。

### B.3 毛（毛利率）

#### 與同業相對位置
- 精技 trailing 12M 毛利率：**7.43%**
- 聯強（2347，通路龍頭）：4-5%
- 精誠（6214）：15-18%（SI 為主）
- 大聯大（3702，IC 通路）：4-5%
- 融程電（3416，AIDC 品牌廠）：30-32%

**精技 7.43% 在通路商中屬中段**，比聯強高（因 AIDC 自有品牌 + solution 佔比），比精誠 SI 大廠低。這個數字**本身不是護城河**——通路業就是低毛利高周轉的商業模式。

#### 近三年趨勢
- 2023：~5-6%
- 2024：~6-7%
- 2025：~7%
- 2026 trailing：**7.43%**

毛利率**穩定微升**，反映 solution / AI server 高 ASP 業務比重提升。但天花板應在 8-10%（若 solution 佔比續升）。

#### 驅動因素
正向：AI server 通路高 ASP、solution 業務佔比、AIDC 自有品牌
負向：通路價格戰、匯率、應收帳款 / 存貨管理成本

#### 可持續性
**中度可持續**。7-8% 毛利在通路商中已算不錯，但要突破 10% 需要商業模式重大轉型（solution / SI / 自有品牌大幅增加）。ROE 18% 是靠**周轉率**（總資產週轉率高），不是毛利率支撐。**D/E 174% 反映通路商應收 + 存貨壓力**，是這個模式必然承受的資本結構。

#### B.3 評分：**2/5**
毛利率 7.4% 是通路業商業模式決定的天花板，不是護城河。ROE 18% 靠周轉不是靠毛利。D/E 174% 反映高財務槓桿。給 2 分是通路商應得的評分。

### C.2 三句話敘事

**第一段（產業位置）**
精技是 1979 年成立的**台灣中型 IT 通路商**，主體業務是代理 Apple、HP、Dell、Lenovo、NVIDIA、Cisco 等品牌賣給企業客戶，兼有 AIDC 自動識別自有品牌業務。2026 上半年因為**企業 AI server 建置浪潮 spillover**，營收 YoY +46%、6 月單月 +87% 創新高，從穩健低毛利通路商**短期轉身為 AI capex 受惠題材股**。但要清楚認知：**精技不是頂級成長股**，本質仍是低毛利高周轉的通路業，護城河偏弱、非龍頭定位，是「短期題材 + 長期穩健配息」的雙軸股票。

**第二段（財務體質）**
7.4% 毛利率是通路業商業模式天花板（雖然中段但不是護城河）、ROE 18% 靠**周轉率**而非毛利、D/E 174% 反映通路商應收 + 存貨壓力。2026 Q1 EPS 1.28 元 + 上半年營收爆發，全年 EPS 有機會挑戰 5 元（trailing 3.5 → +43%）。現價 55.7 forward PE 11x、殖利率 5.4%，**估值便宜 + 高股息 + 成長題材**三合一，是 2026 中小型股中值得注意的組合。

**第三段（風險定價）**
最大風險是 **AI server 通路熱潮的 sustainability**——若 2027 企業 AI capex 進入消化期，精技首當其衝，營收可能立刻回到 YoY +10-20% 水位，EPS 從 5 元掉回 3.5-4 元，PE 拉到 14-16x（跟現在差不多），**估值優勢消失**。次要風險：通路業結構性低毛利、聯強 / 精誠 / 大聯大等大型通路商規模擠壓、AIDC 業務被國際品牌壟斷。**現價 55.7 元從 8/5 高點 61.5 已回檔 -9%**，短線技術面已修正，可視為分批進場區。**適合定位為 5-10% 的衛星倉位**，不建議當核心持股。

## 【E】產業分析師觀點

### E.1 產業位置 / 競爭定位

精技在台灣 IT 通路業排在**中型玩家位置**，明顯落後聯強（2347，龍頭）、精誠（6214，SI 大廠）、大聯大（3702，IC 通路）。這個位置的**優勢**是靈活度高、能接高毛利 solution 訂單；**劣勢**是規模不夠、議價力弱、大型企業客戶通常會找聯強或精誠。精技的差異化在 **AIDC 自有品牌** + **中型企業客戶關係** + **AI server 早期卡位**。

短期主要競爭：(1) **聯強（2347）**：龍頭規模碾壓、(2) **精誠（6214）**：SI 大廠、solution 為主、(3) **大聯大（3702）**：IC 通路 + Enterprise IT、(4) **神通資科（3005 集團）**、(5) **AIDC 領域**：融程電（3416）、國內外自有品牌。精技靠**中型靈活 + 多品牌代理 + AIDC 自有**存活。

### E.2 領先指標

**月營收 MoM / YoY**（最重要）：**2026/6 月 50.92 億 YoY +87.3% 是動能爆發訊號**，5 月 41.01 億 YoY +73.5%、H1 累計 +46.2%。**追蹤 8/10 公布的 7 月營收**：若維持 45 億以上 + YoY +50% 就持續樂觀；若回到 30-35 億 YoY +20% 則要警惕動能減速。

**Q2 財報**：8 月底至 9 月初公布，關鍵看毛利率是否維持 7-8%、Q2 EPS 是否 1.5 元以上（若達，全年 5 元有信心）。

**AI server 出貨比重**：管理層若在法說揭露 AI server 業務佔比，是關鍵重估訊號。

**存貨與應收週轉**：通路商財務健康度指標，若 D/E 進一步上升到 200%+ 是警訊。

**除息公告**：8-9 月間，殖利率 5%+ 對股價有支撐。

### E.3 一句話建議

> **「AI server 通路 spillover 受惠 + 5.4% 高股息 + PE 10-11x 便宜」的中小型衛星股**——基本情境 EPS 5 元支撐 60 元、多頭情境（AI server 超預期）給 84 元想像；現價 55.7 已合理略偏低估，分批可入，適合定位為 **5-10% 衛星倉位**，不建議當核心持股（本質是低毛利通路商）。

### E.4 風險警示

- ⚠️ **AI server 熱潮 2027 消化期**：任何 AI capex 減速都會直接衝擊精技通路業務
- ⚠️ **通路業本質低毛利**：7.4% 毛利天花板明顯，estimated EPS 上限有限
- ⚠️ **競爭者規模擠壓**：聯強、精誠、大聯大規模碾壓，精技結構性劣勢
- ⚠️ **D/E 174% 高財務槓桿**：應收 + 存貨管理不當會嚴重影響現金流
- ⚠️ **法人無 cover**：資訊不對稱雙面刃，機會但也風險

## 【F】思考導航

### F.1 第一個追問：**「2026 EPS 真能達 5 元嗎？」**

Q1 EPS 1.28 × 4 = 5.12 元是基本線性外推，但要考慮：
1. **Q1 是淡季通路本身較弱**，Q2-Q4 通常較旺（企業 IT 預算集中 H2）
2. **6 月營收 YoY +87% 反映 Q2 加速**，Q2 EPS 可能達 1.4-1.5 元
3. **Q3-Q4 若延續，全年 EPS 5.5-6.0 元 achievable**
4. **關鍵是毛利率是否維持 7-8%**：若因 AI server 高單價訂單稀釋管銷費率，op leverage 更強
5. **反面**：若 H2 通路價格戰、AI 熱潮 Q4 開始消化，EPS 可能只到 4.5 元

**個人判斷**：基本情境 5.0-5.5 元合理，樂觀 6 元 achievable, 保守 4.5 元。base case 5 元對應現價 PE 11x 是**合理略偏便宜**。

### F.2 第二個追問：**「精技的護城河真的存在嗎？」**

誠實回答：**護城河偏弱**。通路業本質是低進入門檻、規模至上，精技既沒有龍頭規模（vs 聯強），也沒有 solution 深度（vs 精誠），也沒有 IC 通路廣度（vs 大聯大）。差異化只在 (1) 中型靈活、(2) AIDC 自有品牌小 niche、(3) 特定企業客戶關係。這些差異化在 AI server 熱潮期會被放大（因客戶關係 + 靈活 = 快速響應新需求），但在正常週期會被規模壓制。

**這對投資 implication 是**：精技適合作為**短期 / 中期題材股**（1-2 年），不適合作為**長期核心配置**（10 年 view）。買進理由應該是「殖利率 5.4% + AI server 短期紅利」，而非「長期複利機器」。

### F.3 第三個追問：**「現價 55.7 元的買進 thesis 是什麼？」**

需要分投資人類型：
- **殖利率投資人**：現價 55.7 對應殖利率 5.4%，已合理，若跌到 50 元下對應 6%+ 是好買點
- **成長 / 題材投資人**：AI server 通路 spillover 是 2026-2027 紅利，但 2027 後 sustainability 存疑，建議設定 20-30% 停利
- **價值投資人**：PE 10-11x + PB 2.87x 對應 ROE 18% = PB/ROE 0.16，**便宜**，但要理解低毛利通路商 PB 本應偏低
- **技術面**：8/5 高點 61.5 → 8/7 55.7 -9%，短線整理中，55 是 20MA 附近，破 52 有失守中期支撐風險

**最佳策略**：**分批進場 + 明確停利**——現價 1/3、跌到 50-52 加 1/3、跌到 45-48（黑天鵝）加最後 1/3；停利設 65-70（+17~26%），停損設 45（-19%）。**不建議倉位超過投資組合的 5-10%**（護城河偏弱 + 通路商本質限制）。
